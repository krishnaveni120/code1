# code1
2027 Calendar Generator
A Python project that generates a complete 2027 calendar using Python's Calendar module and Matplotlib.
Features
Displays all 12 months of 2027
Creates a visual calendar
Custom colors and layout
Generates a calendar image
Technologies Used
Python
Matplotlib
Calendar module
How to Run
Install Matplotlib:
pip install matplotlib
Run the Python file:
python calendar.py
Project Purpose
This project was created to practice Python programming, data visualization, and project development.
